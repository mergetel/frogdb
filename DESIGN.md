# FrogDB design

Public surface: an illustrated field guide, led by fictional frog photography. Admin surface: a compact record table and a two-column editor using the same palette.

Cream page background #f7f6ec, deep green foreground #173e32, lime accent #e8f57a. Habitat tags use muted green, aqua, lavender and apricot. Fraunces headings and DM Sans body. Thin dividers, generous page margins, rounded photographs; no dashboard charts.

The catalog uses 2 columns on phones, 3 on tablets, 4 on desktop and 5 on wide displays. The admin table scrolls horizontally on narrow screens. Editor and profile collapse to one column. Controls have visible focus, labels, honest empty/error states and reduced-motion support.

Every frog uses its own cell in the 7 by 5 portrait atlas. Square image frames preserve the shape of the photographed animal. The images, not CSS transformations, provide pose variation.
