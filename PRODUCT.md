# FrogDB

## Platform
web

## Stack
Static HTML, CSS and JavaScript. Implementation choice for a small browser demo with no backend or build requirement.

## Users and purpose
Visitors browse a fictional frog database. Administrators manage frog records. The owner uses this demo for Screenery onboarding and screenshots.

## Capabilities and constraints
Public searchable frog catalog and admin add/edit/delete/publish screens. User selected browser-local persistence, not shared database or login. Work is authored locally without cloning, then committed through the GitHub browser session to mergetel/frogdb. Existing LICENSE must remain untouched.

## Brand commitments
Colorful yet simple. Fictional frogs have plausible sounding names and attributes. Generated pictures look slightly realistic and a little weird. No factual wildlife claims.
